# Nexo Messenger

Современный мессенджер с end-to-end шифрованием, импортом сообщений из Telegram и расширенными возможностями форматирования.

## 🌟 Основные возможности

### 💬 Функциональность мессенджера
- **End-to-End шифрование (E2EE)** - полная конфиденциальность переписки
- **Импорт сообщений из Telegram** - легкая миграция с других платформ
- **Markdown форматирование** - поддержка `**жирный**`, `*курсив*`, `~~зачеркнутый~~`, ```код```
- **Аудиозвонки и видеозвонки** - качественная связь через WebRTC
- **Голосовые сообщения** - запись и отправка голосовых заметок
- **Файловые вложения** - обмен файлами любых типов
- **Ответы на сообщения** - структурированный диалог
- **Пересылка сообщений** - удобный обмен информацией
- **Реакции на сообщения** - эмоциональное общение
- **Поиск по сообщениям** - быстрая находка нужной информации
- **Уведомления в реальном времени** - мгновенные оповещения

### 🔒 Безопасность
- **Сквозное шифрование** (E2EE) с использованием криптографии на эллиптических кривых
- **Server-side Fernet** для импортированных сообщений
- **Управление устройствами** - контроль всех активных сессий
- **Подтверждение новых устройств** - защита от несанкционированного доступа

### 🎨 Пользовательский интерфейс
- **Адаптивный дизайн** - работает на десктопе и мобильных устройствах
- **Темная/светлая тема** - комфортное использование в любое время суток
- **Аватарки пользователей** - персонализация общения
- **Закрепленные сообщения** - важная информация всегда наверху
- **Статусы сообщений** - доставка, прочтение, редактирование

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- PostgreSQL
- Node.js (для WebRTC)

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/Pro100kir2/Nexo/
cd messager
```

2. **Установите Python зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте базу данных PostgreSQL:**
```bash
# Создайте базу данных
createdb nexo_messenger

# Отредактируйте URL базы данных в app.py
DATABASE_URL = "postgresql://username:password@localhost/nexo_messenger"
```

4. **Установите Node.js зависимости:**
```bash
npm install
```

5. **Запустите приложение:**
```bash
python app.py
```

6. **Откройте в браузере:**
```
http://localhost:8000
```

1. Нажмите на иконку профиля в сайдбаре
2. Используйте функцию поиска друзей
3. Отправьте запрос на добавление в друзья
4. Дождитесь подтверждения от другого пользователя

### Основные функции чата

#### Отправка сообщений
- **Текстовые сообщения:** введите текст и нажмите Enter или кнопку отправки
- **Голосовые сообщения:** зажмите кнопку микрофона для записи
- **Файлы:** перетащите файл в окно чата или нажмите кнопку прикрепления
- **Markdown форматирование:**
  - `**жирный текст**` → **жирный текст**
  - `*курсив*` или `_курсив_` → *курсив*
  - `~~зачеркнутый~~` → ~~зачеркнутый~~
  - ```код``` → `код`

#### Ответы и пересылка
- **Ответ на сообщение:** нажмите и удерживайте сообщение → выберите "Ответить"
- **Пересылка:** нажмите и удерживайте сообщение → выберите "Переслать"

#### Реакции
- Наведите на сообщение → нажмите на эмодзи для добавления реакции
- Поддерживаются множественные реакции на одно сообщение

### Импорт из Telegram

1. **Экспорт из Telegram:**
   - Откройте Telegram Desktop
   - Настройки → Продвинутые → Экспорт данных
   - Выберите "Сообщения" и сохраните файл

2. **Импорт в Nexo:**
   - Нажмите "Импорт Telegram" в сайдбаре
   - Выберите экспортированный файл
   - Укажите ваше имя в Telegram
   - Выберите чат для импорта

### Аудиозвонки и видеозвонки

1. **Начало звонка:**
   - Откройте чат с нужным пользователем
   - Нажмите на иконку 📞 (аудио) или 📹 (видео)

2. **Во время звонка:**
   - Мьют/анмьют микрофона
   - Включение/выключение камеры
   - Завершение звонка

### Управление устройствами

1. **Просмотр активных устройств:**
   - Сайдбар → Устройства
   - Список всех авторизованных устройств

2. **Подтверждение новых устройств:**
   - При входе с нового устройства вы получите уведомление
   - Подтвердите или отклоните доступ

## 🔒 Безопасность

### End-to-End шифрование
- Используются криптографические пары RSA/ECDH
- Каждое сообщение шифруется отдельно для каждого получателя
- Сервер не имеет доступа к содержимому сообщений

### Защита данных
- Все пароли хешируются
- Сессии защищены JWT токенами
- Подтверждение новых устройств

## 🐛 Устранение неполадок

### Частые проблемы

**Проблема:** Сообщения не отправляются
**Решение:** Проверьте подключение к интернету и статус WebSocket

**Проблема:** Не работает импорт Telegram
**Решение:** Убедитесь что файл экспорта в формате JSON и содержит сообщения

**Проблема:** Нет звука в звонках
**Решение:** Проверьте разрешения микрофона в браузере

**Проблема:** Медленная загрузка чатов
**Решение:** Очистите кэш браузера или перезагрузите страницу

### Логирование
Приложение использует детальное логирование. Проверьте консоль браузера для диагностики проблем.
